# Сердечко: запуск на GitHub + Vercel

В папке:
- `index.html` — весь сайт
- `api/` — серверная часть: короткие ссылки (`save.js`, `get.js`), бот Купидон (`webhook.js`, `notify.js`, `check.js`, `setup.js`), общий файл `_lib.js`
- `vercel.json` — делает ссылки вида `сайт/l/Ab3dE9xK`
- `package.json` — пустой, нужен Vercel

## Шаг 1. Репозиторий на GitHub
1. На github.com нажми **New repository**, назови `serdechko`, создай.
2. **Add file → Upload files**: перетащи `index.html`, `vercel.json`, `package.json` и папку `api` целиком (7 файлов внутри), нажми **Commit changes**.
   Если папка не перетаскивается, создай файлы вручную: **Add file → Create new file**, в имени напиши `api/save.js` и так далее.

## Шаг 2. Подключи Vercel
1. На vercel.com войди через GitHub.
2. **Add New → Project**, выбери репозиторий, **Framework Preset** оставь **Other**, нажми **Deploy**.

## Шаг 3. Хранилище (обязательно)
Здесь лежат короткие ссылки и личные коды пользователей.
1. В проекте на Vercel: **Storage** (или **Marketplace**) → **Upstash Redis** (есть бесплатный тариф) → подключи к проекту.
2. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` (или `UPSTASH_REDIS_REST_*`) добавятся сами.

## Шаг 4. Бот Купидон
1. В Telegram открой **@BotFather**, `/newbot`, скопируй **токен**. Никому его не показывай. Username бота должен совпадать со строкой `const BOT="my_serdechko_bot";` в `index.html` (без `@`).
2. На Vercel: **Settings → Environment Variables**, добавь:
   - `BOT_TOKEN` — токен от BotFather
   - `WEBHOOK_SECRET` — любая длинная случайная строка из латинских букв и цифр
3. **Deployments** → у последней строки `⋯` → **Redeploy** (без этого переменные не подхватятся).
4. Открой в браузере одну ссылку (подставь свой секрет):

   `https://serdechko-omega.vercel.app/api/setup?key=ТВОЙ_WEBHOOK_SECRET`

   Она сама подключит бота к сайту, поставит имя «Купидон», описание и меню команд. Ответ должен содержать `"ok":true` у каждого пункта. Если имя не поменялось (Telegram ограничивает частую смену), переименуй бота в BotFather: `/setname`.

## Как это работает для пользователя
Это же написано на главной странице сайта (раздел «Как получать ответы в Telegram»).
1. Открыть Купидона и нажать «Старт». Telegram не разрешает ботам писать первыми.
2. Бот присылает личный код из 10 цифр. Если забыл, команда `/code`.
3. При создании вставить код в поле «Код из бота Купидон». Под полем есть ссылка «Как достать код?», она ведёт на инструкцию на главной. Сайт сам проверит, что такой код существует.

## Проверка
1. Напиши боту `/start`: он пришлёт код и кнопки «Открыть «Сердечко»» и «Как вставить код».
2. На сайте создай приглашение и вставь код. Появится «✅ Код верный».
3. Скопируй ссылку и открой в **новой вкладке или на другом телефоне**. Кнопка «Открыть как получатель» только показывает превью и ничего не отправляет.
4. Нажми «Да»: бот напишет тебе.

## Что важно знать про приватность
- Код у каждого человека свой: случайные 10 цифр, привязанные к его чату. Угадать чужой код практически невозможно, а настоящий номер чата нигде не используется.
- Получатель кода автора не видит: на сервере хранится код, а получателю отдаются только данные приглашения. Уведомления идут по номеру ссылки.
- Бот не подтверждает чужие коды: если написать ему чужой код, он ничего не раскроет.
- Любой, у кого есть ссылка, видит содержимое приглашения. Отправляй её только тому, кому она предназначена.
- Ссылки хранятся 2 года. Старые длинные ссылки (`?i=...`) продолжают открываться.
- Если токен попал в чужие руки, перевыпусти его в @BotFather командой `/revoke`, обнови `BOT_TOKEN` на Vercel и сделай Redeploy.
