# Сердечко: запуск на GitHub + Vercel

В папке:
- `index.html` — весь сайт
- `api/` — серверная часть для Telegram-бота (три маленьких файла, Vercel запускает их сам)
- `README.md` — эта инструкция

Всё лежит в одном репозитории и работает на одном адресе. Cloudflare и другие сервисы не нужны.

## Шаг 1. Репозиторий на GitHub
1. На github.com нажми **New repository**, назови `serdechko`, создай.
2. **Add file → Upload files**: перетащи `index.html` и папку `api` целиком (с тремя файлами внутри), нажми **Commit changes**.
   Если папка не перетаскивается, создай файлы вручную: **Add file → Create new file** и в имени напиши `api/notify.js`, затем вставь содержимое. То же для `api/webhook.js` и `api/_lib.js`.

## Шаг 2. Подключи Vercel
1. Зайди на vercel.com, войди через GitHub.
2. **Add New → Project**, выбери репозиторий `serdechko`.
3. **Framework Preset** оставь **Other**, остальное не трогай, нажми **Deploy**.
4. Через минуту сайт откроется по адресу вида `https://serdechko.vercel.app`. Запомни его.

Без бота сайт уже работает целиком. Если в поле Telegram указать `@username`, у получателя появится кнопка «Сообщить в Telegram».

## Шаг 3. Бот, чтобы ответы приходили сами
1. В Telegram открой **@BotFather**, отправь `/newbot`, придумай имя и username (заканчивается на `bot`). Скопируй **токен**. Никому его не показывай.
2. На Vercel открой проект: **Settings → Environment Variables** и добавь:
   - `BOT_TOKEN` — токен от BotFather
   - `WEBHOOK_SECRET` — любая длинная случайная строка из латинских букв и цифр
3. Открой **Deployments**, у последней строки меню `⋯` → **Redeploy**. Без этого переменные не подхватятся.
4. Подключи бота к сайту: открой в браузере ссылку (подставь свои значения)

   `https://api.telegram.org/botТОКЕН/setWebhook?url=https://ТВОЙ-САЙТ.vercel.app/api/webhook&secret_token=ТВОЙ_WEBHOOK_SECRET`

   Должно ответить `{"ok":true,...}`. Используй именно основной адрес сайта, а не адрес отдельного деплоя из списка Deployments.
5. В `index.html` найди строку `const BOT="";` и впиши username бота без `@`:

   `const BOT="username_бота";`

   Сохрани файл на GitHub (значок карандаша у файла → Commit). Vercel сам выкатит новую версию.

## Проверка
1. Напиши своему боту `/start`. Он пришлёт **код** (число).
2. На сайте вставь этот код в поле Telegram при создании.
3. Скопируй готовую ссылку и открой её в **новой вкладке или на другом телефоне**. Кнопка «Открыть как получатель» только показывает превью и в Telegram ничего не отправляет.
4. Нажми «Да»: бот напишет тебе.

## Что важно знать
- Получатель в своей ссылке может найти твой код. Сервер отправляет только готовые типы сообщений («открыл», «ответил» и т. п.), а не произвольный текст, и принимает запросы только с твоего сайта. Но недоброжелатель с curl всё равно мог бы засыпать тебя уведомлениями. Для личных подарков этого достаточно.
- Если у сайта подключён свой домен, в команде `setWebhook` используй его.
- Если токен попал в чужие руки, перевыпусти его в @BotFather командой `/revoke`, обнови `BOT_TOKEN` на Vercel и сделай Redeploy.
